Preset determinism (PRD §8.2)

Renders the Get Back preset twice through an OfflineAudioContext. The second render mutates knobs, then re-applies the preset before rendering — so if applyPreset() is exhaustive (no state leaks in from the mutation), the two waveforms must be identical.

Notes: the noise gate is held open during offline rendering (no requestAnimationFrame). The compressor pedal is forced OFF for this test because Chromium's DynamicsCompressorNode is itself non-deterministic in OfflineAudioContext (it differs between two identical renders) — testing it would test the browser, not our engine. Everything else in the chain (preamp waveshapers, tonestack filters, power-amp soft clip, gains, IR mix) renders bit-identically, so this validates the real target: that mutating knobs and re-applying the preset fully restores the graph with zero state leakage.
